## identify_customer

Start a GIMME voice session for the signed-in customer. Call this first: every other tool needs the session_id it returns. Identity comes from the OAuth token, never from arguments.

- **Classification:** READ
- **Scopes:** `gimme.customer.read`
- **Side effects:** Creates a short-lived voice session (state only; nothing customer-visible).
- **Idempotency:** Each call opens a new session.
- **Errors:** `AUTHENTICATION_REQUIRED`, `INSUFFICIENT_SCOPE`, `INVALID_REQUEST`, `UNKNOWN_ERROR`, `CUSTOMER_NOT_FOUND`

| Argument | Required | Description |
| --- | --- | --- |
| `platform` | yes | string |
| `platform_user_id` | yes | The assistant platform's stable id for this user (must be linked to the GIMME account). |
| `platform_session_id` | no | string |
| `conversation_id` | no | Platform conversation id; part of the idempotency key for mutations. |

## create_order_intent

Validate a basket end to end — products, stock, delivery, the customer's eligibility, payment method, live price — and hold it as an order intent awaiting the customer's confirmation. Returns the exact summary and amount to put to the customer. Moves no money and reserves nothing.

- **Side effects:** Creates an order intent (expires in 5 minutes). Supersedes the session's previous unconfirmed intent.

## request_authorization

Ask the customer — not the model — to confirm an order intent for its exact total. GIMME asks the customer directly through the client (MCP elicitation) or a GIMME-hosted confirmation link. Never call this unless the customer has asked to order; never claim they confirmed. Returns AUTHORIZED with a single-use authorization_token, DECLINED, or PENDING_CUSTOMER_CONFIRMATION.

- **Classification:** PRE_TRANSACTION
- **Scopes:** `gimme.cart.create`
- **Side effects:** Prompts the customer. On confirmation, issues a purchase authorization bound to this intent's items, total, address and payment method (expires in 2 minutes, single use).
- **Idempotency:** Each call prompts the customer again until the intent is confirmed, declined or expires.
- **Errors:** `AUTHENTICATION_REQUIRED`, `INSUFFICIENT_SCOPE`, `INVALID_REQUEST`, `UNKNOWN_ERROR`, `ORDER_INTENT_NOT_FOUND`, `ORDER_EXPIRED`, `ORDER_INTENT_INVALID_STATE`, `ORDER_ALREADY_CREATED`

| Argument | Required | Description |
| --- | --- | --- |
| `order_intent_id` | yes | Order intent id awaiting confirmation. |

## authorize_payment

Authorize payment for a confirmed order intent with the customer's saved, tokenised payment method (or a wallet token). Requires the purchase authorization from request_authorization. Never accepts card numbers.

- **Classification:** HIGH_RISK_MUTATION
- **Scopes:** `gimme.payment.authorize`
- **Side effects:** Places a payment authorization (hold) for the intent total with GIMME's payment provider.
- **Idempotency:** At most one provider authorization per order intent, however often this is retried (provider idempotency key derived from the intent).
- **Errors:** `AUTHENTICATION_REQUIRED`, `INSUFFICIENT_SCOPE`, `INVALID_REQUEST`, `UNKNOWN_ERROR`, `ORDER_INTENT_NOT_FOUND`, `AUTHORIZATION_REQUIRED`, `CONFIRMATION_MISMATCH`, `ORDER_EXPIRED`, `ORDER_INTENT_INVALID_STATE`, `SESSION_INVALID`, `PAYMENT_REQUIRED`, `PAYMENT_DECLINED`, `PAYMENT_FAILED`, `PAYMENT_TIMEOUT`

| Argument | Required | Description |
| --- | --- | --- |
| `order_intent_id` | yes | Confirmed order intent id. |
| `authorization_token` | no | From request_authorization / confirm. Omit only when the customer confirmed out-of-band (hosted confirmation page); the server then uses the authorization it recorded for this intent. |
| `wallet_token` | no | Single-use Apple Pay / Google Pay payment token, when the intent was created with a wallet. Never a card number. |

## place_order

Create the GIMME order. Re-checks eligibility, delivery, stock (reserved atomically) and price first. If the price changed, nothing is charged and a replacement intent is returned for the customer to re-confirm.

- **Classification:** HIGH_RISK_MUTATION
- **Scopes:** `gimme.order.create`
- **Side effects:** Reserves stock, creates the order in GIMME's OMS and captures the authorized payment.
- **Idempotency:** Required idempotency_key. A repeat with the same key returns the original result (idempotent_replay: true); the same key for a different order is refused; a second key for an already-placed intent returns ORDER_ALREADY_CREATED.
- **Errors:** `AUTHENTICATION_REQUIRED`, `INSUFFICIENT_SCOPE`, `INVALID_REQUEST`, `UNKNOWN_ERROR`, `SESSION_INVALID`, `ORDER_INTENT_NOT_FOUND`, `AUTHORIZATION_REQUIRED`, `ORDER_EXPIRED`, `ORDER_ALREADY_CREATED`, `ORDER_INTENT_INVALID_STATE`, `INVENTORY_CHANGED`, `PRICE_CHANGED`, `AGE_VERIFICATION_REQUIRED`, `ACCOUNT_RESTRICTED`, `OUTSIDE_SERVICE_AREA`, `STORE_CLOSED`, `DELIVERY_UNAVAILABLE`, `PAYMENT_FAILED`, `IDEMPOTENCY_CONFLICT`

| Argument | Required | Description |
| --- | --- | --- |
| `order_intent_id` | yes | Order intent with an authorized payment. |
| `payment_authorization_id` | yes | From authorize_payment. |
| `idempotency_key` | yes | Stable across retries. Recommended: <platform>:<customer_id>:<conversation_id>:<order_intent_id>. |

## cancel_order

Ask GIMME to cancel an order. GIMME decides; once an order is being packed or is on its way it usually can't be. Returns the actual outcome.

- **Classification:** HIGH_RISK_MUTATION
- **Scopes:** `gimme.order.cancel`
- **Side effects:** Cancels the order in GIMME's OMS and releases the payment, where permitted.
- **Idempotency:** Cancelling an already-cancelled order reports its current state.
- **Errors:** `AUTHENTICATION_REQUIRED`, `INSUFFICIENT_SCOPE`, `INVALID_REQUEST`, `UNKNOWN_ERROR`, `ORDER_NOT_FOUND`

| Argument | Required | Description |
| --- | --- | --- |
| `order_id` | yes | GIMME order id. |
| `reason` | no | string |
