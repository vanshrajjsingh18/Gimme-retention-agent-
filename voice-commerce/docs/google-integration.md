# Google integration contract

## Which Google surface

Google shut down Conversational Actions (Actions on Google / Actions SDK / Actions Builder) on 13 June 2023, so this integration does not target them (§26). Their transaction concepts are kept here: physical goods, merchant-managed payment, account linking, and an explicit transaction decision.

The adapter is one stable server contract, `POST /v1/voice/adapters/google/fulfillment`, that any surface Google approves for GIMME can call. As of this writing, the candidates are:

| Surface | How it reaches GIMME | Confirmation | Notes |
| --- | --- | --- | --- |
| **GIMME Android app exposing actions to Gemini / Assistant** (App Actions / App Functions) | Assistant or Gemini invokes the app's declared capability. The app calls the fulfillment endpoint with its own first-party OAuth token. | In-app, on-device: BiometricPrompt or device credential, then `confirmation.device_authenticated: true` | Recommended. It is the closest equivalent of Siri + App Intents. |
| **A Google agent surface with account linking** (when available to GIMME) | The surface calls the endpoint with the account-linked GIMME token. | If the surface can't show a GIMME-controlled confirmation, the server returns `expect: APP_HANDOFF` or `DEVICE_CONFIRMATION` | A third-party surface never gets `gimme.order.confirm`. |
| **Gemini or another agent as an MCP client** | `/mcp` with OAuth | MCP elicitation, or the hosted confirmation page | Same as any agent. See [mcp-tools.md](mcp-tools.md). |

**Verify the current surface, API names and policy for alcohol transactions with Google at implementation time.** These surfaces change, and alcohol sales are restricted on several Google commerce surfaces. Nothing above the adapter has to change when the surface does.

## Account linking

```
Google identity  ──(account linking: OAuth 2.0 authorization code + PKCE against GIMME's authorization server)──▶  GIMME customer
                 GIMME stores (platform = GOOGLE, platform_user_id) ↔ customer_id
```

- On the Android path the app is already signed in to GIMME and uses its own token.
- `google_user_id` must be the id GIMME recorded at linking. An id that isn't linked returns `CUSTOMER_NOT_FOUND` with `LINK_ACCOUNT`.
- Scopes: request `AGENT_SCOPES` (everything except `gimme.order.confirm`) for third-party surfaces, and `ALL_SCOPES` for the GIMME Android app.

## Fulfillment contract

Request:

```json
{
  "handler": "gimme.order.usual | gimme.order.items | gimme.order.reorder_last | gimme.order.select | gimme.order.confirm | gimme.order.decline | gimme.order.status | gimme.order.cancel | gimme.order.receipt",
  "google_user_id": "…",
  "conversation_id": "…",
  "session_id": "VS-… (optional; returned on the first turn)",
  "params": { "items": [{ "query": "Heineken", "quantity": 12, "unit": "UNIT" }], "selected_sku": "HEI6PK", "order_id": "GIMME-…" },
  "confirmation": { "confirmed_total": 28.96, "device_authenticated": true, "method": "ANDROID_APP_CONFIRMATION", "confirmation_id": "…" },
  "google_pay_token": "… (single-use, only if the intent was created for GOOGLE_PAY)"
}
```

Response:

```json
{
  "session_id": "VS-…",
  "prompt": { "speech": "That's one Heineken 6-pack. It's $28.96 delivered to home. Want me to place it?", "text": "…" },
  "expect": "CONFIRMATION",
  "end_conversation": false,
  "transaction_decision": {
    "order_intent_id": "OI-…",
    "amount": { "currency_code": "NZD", "units": 28, "nanos": 960000000 },
    "merchant_name": "GIMME",
    "summary": "one Heineken 6-pack — $28.96 NZD, delivered to Home, paid with Visa ending 4242",
    "requires_device_authentication": true
  },
  "suggestions": [{ "sku": "…", "title": "…", "price": 19.99 }],
  "order": { "order_id": "GIMME-…", "status": "CONFIRMED", "estimated_minutes": 45, "total": 28.96 },
  "error_code": "PRICE_CHANGED"
}
```

`amount` uses the Google money shape (`units` plus `nanos`), so a Google transaction UI can show it without converting.

## Handler mapping

| Handler | Dialog intent | Service path |
| --- | --- | --- |
| `gimme.order.usual` | `ORDER_USUAL` | `resolveItems(USUAL)` → `createOrderIntent` |
| `gimme.order.items` | `ORDER_ITEMS` | `resolveItems(ITEMS)` → clarify or `createOrderIntent` |
| `gimme.order.select` | `SELECT_OPTION` | continue resolution with the chosen SKU |
| `gimme.order.reorder_last` | `REORDER_LAST` | `reorderPrevious` |
| `gimme.order.confirm` | `CONFIRM` | `confirmOrderIntent` → `authorizePayment` → `placeOrder` |
| `gimme.order.decline` | `DECLINE` | intent cancelled |
| `gimme.order.status` | `ORDER_STATUS` | `getOrderStatus` |
| `gimme.order.cancel` | `CANCEL_ORDER` | `cancelOrder` |
| `gimme.order.receipt` | `RECEIPT` | `getReceipt` |

## Example conversations (§19)

These were generated by `npm run demo` against the sandbox.

```
Customer: Hey Google, get me some Heineken from GIMME.
Google:   We have three Heineken options: Heineken 6-pack, Heineken 12-pack and Heineken 24-pack. Which one?
Customer: The six-pack.
Google:   That's one Heineken 6-pack. It's $28.96 delivered to home. Want me to place it?
Customer: Yes.
Google:   Done. Your GIMME order is confirmed and should arrive in about 45 minutes.

Customer: Hey Google, order the Sandbox IPA from GIMME.
Google:   That's one Sandbox Repriced IPA 6-pack. It's $28.97 delivered to home. Want me to place it?
Customer: Yes.
Google:   The price has changed to $36.47. Do you want me to continue?          ← nothing charged at either price yet
Customer: Yes, go ahead.
Google:   Done. Your GIMME order is confirmed and should arrive in about 45 minutes.

Customer: Hey Google, order a Corona twelve-pack from GIMME.
Google:   Corona Extra 12-pack is currently unavailable. Would you like Heineken 12-pack or Steinlager Pure 12-pack instead?

Customer: Hey Google, reorder my last GIMME order.
Google:   Your last GIMME order is one Corona Extra 12-pack. It's $45.96 delivered to home. Want me to place it?
```
